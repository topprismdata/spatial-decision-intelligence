# 自绘围栏可行性验证报告

> 需求锚点："这些围栏毕竟是从别的地方采购的，你能否以这个作为学习样本，自己绘制呢"
>
> 结论先行：**可以自绘，但替代采购的定位是"低成本粗绘 + 高价值人工复核"**。
> 在"名称 + 种子点 + 面积"三种输入下，最优单法 A3 的 IoU 中位为 **0.392**，
> 三法择优后为 **0.457**（41.3% 的围栏 IoU>0.5，14.0% >0.7）。

---

## 一、实验设定

### 1.1 学习样本（采购围栏的形状先验）

对全量 9,039 条采购围栏（北京城区 7,431 + 石家庄 1,608）统计形状先验：

| 先验维度 | 结论 |
|---|---|
| 面积分布 | 北京中位 **21,073㎡**，lognormal（σ=1.54），跨 3 个数量级 |
| 朝向 | **76% 朝向贴正交网格（±10°）** —— 城市围栏高度对齐路网 |
| 顶点数 | 中位 **6** —— 绝大多数是简化的直边多边形 |
| 紧凑度 | 中位 0.49（Polsby-Popper） |
| 面积属性 | 底表 `面积[内置]` 与围栏实际面积 log-log 相关 **r=1.000**（单位 km²，系数 1.001e6）→ **采购数据自带面积字段，现实自绘的输入清单应包含它** |

### 1.2 评估窗口与样本

- **W1 老城（西城，116.37, 39.93）**：74 条围栏，院落级粒度（500–1,500㎡ 为主）
- **W2 朝阳（东部，116.43, 39.93）**：69 条围栏，小区级粒度
- 底图数据：Overpass API 下载建筑足迹（W1 1,648 栋 / W2 651 栋）+ 全类型路网（含 footway/service/steps，W1 602 ways / W2 800 ways）
- 评估指标：自绘多边形与采购真值的 **IoU**（交并比）

## 二、四代生成器演进

| 代际 | 方法 | 关键改进 | IoU 中位 | >0.5 | >0.7 |
|---|---|---|---|---|---|
| A1 | 主干路网街区 polygonize | — | 0.032 | — | — |
| B1 | 建筑 12m 缓冲簇 | — | 0.037 | — | — |
| C | 先验面积圆 | 引入先验面积 | 0.199 | 8.4% | 0.7% |
| A2 | 全类型路网街区 | 胡同级街区 + 粒度自适应 | 0.190 | 10.8% | 1.4% |
| B2 | 建筑簇 v2 | 粒度自适应 | 0.124 | 7.0% | 0.0% |
| **A3** | **街区 + 真实面积裁剪** | **引入面积属性** | **0.392** | **31.7%** | **10.1%** |
| B3 | 建筑簇 + 真实面积裁剪 | 同上 | 0.289 | 18.8% | 3.4% |
| C3 | 真实面积圆 | 同上 | 0.389 | 28.0% | 4.9% |
| A4/B4 | 300m 内面积最匹配块 | 方向信息缺失 | 0.000 | — | 弃用 |
| **择优** | **A3/B3/C3 取最大** | 交付口径 | **0.457** | **41.3%** | **14.0%** |

### 演进中的三个关键教训

1. **粒度失配是一代失败的主因**（IoU≈0.03 的"假 bug 真问题"）：老城采购围栏是院落级，而纯主干路网街区是 50 万㎡ 超级街区。补下全类型路网（含 footway/service）后才能切出院落粒度。
2. **面积属性是最大杠杆**：A2→A3 只改一件事——用真实面积（r=1.000 的那列）做裁剪/贪心并块，IoU 中位 **0.190 → 0.392**，直接翻倍。说明自绘的核心信息排序：**面积 > 地图结构 > 形状先验**。
3. **A4/B4"面积最匹配"反直觉地失败**（IoU=0.000）：在种子点 300m 内选面积最接近目标的街区，会选到**方向错误的块**——种子点必须落在块内（种子街区法），而不是在邻域里挑面积。

## 三、最优方法 A3 的工作流

```
输入：名称 + 种子点（经纬度）+ 面积(km²)
  │
  ├─ 1. 种子点定位：在全类型路网 polygonize 得到的街区面里找含种子点的块
  ├─ 2. 粒度自适应：贪心并入邻块，直到 ≥ 0.5×目标面积（最多 4 轮）
  ├─ 3. 面积裁剪：若 > 3×目标面积，用目标面积的圆/收缩裁剪到上界
  └─ 4. 输出：街区边界（天然贴路网、正交朝向、顶点少）
```

---

## 四、诚实边界

1. **粒度失配是固有上限**：院落级围栏（老城）的 IoU 天花板低于小区级（朝阳），因为路网街区粒度无法切到单个院落。择优口径下仍有 ~59% 的围栏 IoU≤0.5。
2. **C3 圆基线高达 0.389** 的另一面：近半数采购围栏的形状信息量有限（规则近圆/近方），自绘对这部分的"形状还原"价值不大，价值在**边界贴路网**（A3）和**不漏地块**（recall）。
3. **本实验输入含"真实面积"**——现实中若采购源只有名称+点（无面积），自绘效果回落到 A2 水平（IoU≈0.19），需靠名称语义（"XX小区"→ POI 检索拿范围）补面积。
4. 样本仅覆盖北京两窗口 143 条；石家庄未验证，但方法与城市无关。

## 五、采购替代可行性结论

| 场景 | 建议 |
|---|---|
| 已有名称+点+面积（本底表情形） | **自绘可行**：A3 择优 IoU 中位 0.457，可作为初稿批量生成，人工只复核低 IoU 尾部 |
| 只有名称+点 | 自绘降级为粗绘（IoU≈0.19），建议先补 POI/建筑面积再绘 |
| 高精度业务（配送围栏精确扣款） | 自绘不能直接替代采购，但可作**采购数据的质检参照**：采购围栏与自绘街区 IoU 过低 → 疑似采购质量问题 |

**总体判断**：自绘围栏已具备"60 分初稿"能力。结合本项目此前结论（786 条问题围栏、248 对重叠），自绘街区还可作为**第三方独立参照系**，用于交叉暴露采购围栏的粒度异常和位置漂移。
